# EU27 Vaccine Price Corridor

Interactive tool that suggests GNI-adjusted net prices per dose for seasonal influenza, COVID-19 and the mRNA flu + COVID combination across the 27 EU member states.

Live page: https://philippe145.github.io/pricing-tool/

Default anchor prices are illustrative p-valorem estimates built from public sources, not tender awards or company pricing. All inputs are editable in the page and are stored only in each viewer's browser.

The whole tool is the single file `index.html`; it needs no build step or server.
